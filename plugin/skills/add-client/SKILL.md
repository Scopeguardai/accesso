# Add a client

A client needs two things before a deck can be made: a Design System (the brand) and a
knowledge folder (the facts). Set up both.

## 1. Collect the brand material

Ask for whatever exists: brand guidelines, logo files, font files or font names, a
presentation template or an on-brand deck, and photography. Guidelines plus a logo are
the minimum. If nothing is supplied, stop and say what is needed.

## 2. Create the Design System

Create a Design System titled exactly with the client's name; new-deck finds clients by
this title. Build it from the supplied material only:

- Exact colour values, fonts and logo files from the source. Never approximate a logo
  or invent a colour.
- A brand book covering voice, typography, colour, layout, imagery and logo use,
  written as rules a deck must follow.
- The photography, each image with a note on what it is for.
- A short list of open points wherever the material is unclear or contradicts itself.

Tell the person what was taken from where, and list the open points for them to confirm.

## 3. Create the knowledge folder

In Google Drive, find the folder `Accesso knowledge`, creating it if it does not exist,
and inside it create a folder named exactly as the client. Confirm with the person
before creating anything in Drive.

Explain how the folder works:

- One document per topic, short and factual: company facts, figures, customers,
  milestones, team, product descriptions.
- Facts as plain sentences with their numbers, dates and where they came from.
- A document whose title starts with "Draft" is treated as unconfirmed.
- Nothing from one client's folder is ever used for another client.

If the person supplied source text, offer to turn it into the first documents, each
titled "Draft" until someone at the client has checked it.

## 4. Confirm

Reply with the link to the Design System, the link to the knowledge folder, the open
points on the brand, and the knowledge still missing. Then offer to make a first deck
with the new-deck skill.
